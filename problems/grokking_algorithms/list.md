# Grokking Algorithms
## Data Structures
- [x] Arrays -> a list where the storage are sequential, shift is required for add or del, but you can access elements by it idx
- [x] Linked Lists -> a list where the storage are non sequential, shift is not required for add or del elements, but you cant access elements by it idx
- [x] Stacks -> literally a stack, where the last in is the first out          [1][2][3] -> [1][2]
- [x] Queues -> litarally a queue, where the first in is the first out         [1][2][3] -> [2][3]
- [x] Hash Tables -> a table where you use a key to access the value           {12345, "wesley"}

## Sorting Algorithms

## Searching Algorithms
